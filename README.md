## Projetos

**Renova Terra**
Plataforma que conecta voluntários, ONGs, empresas e órgãos públicos em ações
socioambientais. Sistema de login, área para empresas parceiras, páginas de equipe,
doações — o pacote completo de uma startup de impacto social.

**Framework RPG**
Base para construção de jogos de RPG do zero: lógica de personagens, sistemas de
turno e estrutura pensada para ser reaproveitada em outros projetos, não só num jogo só.

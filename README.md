## Descrição

Full stack, mas de verdade: entro no projeto quando é só uma ideia e fico até o deploy.
Gosto de resolver o problema chato que ninguém quer pegar e de deixar interface bonita
sem virar refém de framework nenhum.

Atualmente com duas coisas na bancada: uma plataforma de voluntariado ambiental
e um framework para RPGs — dois extremos completamente diferentes, do jeito que eu gosto.

## Sobre mim

Desenvolvedor Full Stack, atuando do primeiro rascunho de uma ideia até o deploy em produção. Trabalho com HTML, CSS, JavaScript, Java e Python, e gosto especialmente da parte que a maioria evita: resolver o problema chato que trava o projeto e ainda deixar a interface bonita, sem depender de framework nenhum para isso.

Prefiro entrar no projeto ainda cru, quando é só uma ideia solta, e acompanhar até ele estar rodando de verdade. Curto tanto a parte de estrutura e lógica quanto a de deixar tudo com personalidade visual, sem cair em aparência de template genérico.

Sempre com algo em produção, nem sempre terminado no prazo que eu gostaria — mas sempre terminado.

## Por que trabalhar comigo

- Entrego o projeto inteiro: da concepção à interface final, sem depender de terceiros para fechar as pontas.
- Não fujo da parte chata do código — geralmente é onde o projeto trava, e é onde eu entro.
- Interface com identidade visual própria, sem parecer template pronto ou gerado às pressas.
- Transito bem entre dois extremos: sistemas voltados para impacto social e sistemas de lógica e regras complexas (como um framework de RPG).
